# 城市 v18：十栋正式模型与东部新城区

基于 v17（`9ce7807e5da5532a841e9dafa0583a207068d938`），仅替换 **03 老城区、08 主岛东北**，其他 **16 个区块沿用原文件**。

## 本轮落位

- 本批历史立面 57、58、59、60、61、62、63、66 八栋，分别替换老城八栋沿街占位楼，每型使用一次，保留原始比例与贴图。老城沿街仍为 **120 栋**，后巷仍为 80 栋，合计 200 栋。骑楼池原有 10 型维持各 3 栋，新 8 型各 1 栋，均不超过每型 3 栋的限制。
- 本批历史立面 57 记为 **H57**，源文件为 `historic_facade_57b.glb`，与此前的现代店面 57 分开管理，没有覆盖旧素材。
- **64 号商场**与**65 号警察总部**布置在北部主岛东侧、主街东侧的内陆地块，位于立交匝道以北；入口朝主街，铺地和步道接入现有人行道。
- 划定 **东部新城区 150,350 m²（约 0.150 km²）**。范围串联原有东侧居住片区和北侧公共设施，分为商业中心、公共服务、原有居住、后续商务与居住用地、立交绿化缓冲带。原有居住片区包含 22 栋既有占位体块，本轮加入两栋正式模型，共 24 个既有/本轮建筑单元。斜线区域为预留地，尚未建楼，不计作已建建筑。
- 全城 **543 栋**，比 v17 净增 2 栋。CBD、市政区、天明预留地、公寓区、海岸及道路骨架保留。

新模型分别做了楼底基础、连续地面及入口衔接，基础顶面与地面铺装分开，避免共面重叠造成宽黑边。本次没有增加外接连续雨棚，也没有拉伸或镜像模型。

## 使用增量

取得一套完整且校验通过的 v17 区块目录后运行：

```bash
python3 reassemble.py --baseline-dir /path/to/v17/districts --out /path/to/v18/districts
```

脚本逐一校验基准、分卷、压缩流和解压后的 GLB，保留原基准目录。只取本次两区块可省略 `--baseline-dir`。导入时先移除旧 03/08 再加载新版，根位置、旋转为 0，缩放为 1，不叠加加载。

清单与 SHA256 在 `manifest.json`，完整 18 区块来源在仓库 `design/city/districts/current_sources_v18.json`。只附带两块改动模型、十份必要的新原始素材、元数据、处理脚本和六张预览，没有重复上传其余区块或完整 Blender 工程。

## 区划与验证

`metadata/new_town_plan.json` 和 `metadata/new_town_v18.geojson` 保存实际边界、用地多边形、开发阶段与建筑清单。坐标为 **Blender 世界 XY、单位米**，不是经纬度；没有把区划轮廓涂到实景模型上。`previews/05_newtown_plan_v18.png` 提供中文标注图，其余预览为实际场景渲染。

原生检查覆盖十栋新楼的比例、落位、邻楼与道路相交、接地和入口连接；两份 GLB 全部重新导入，最大世界坐标误差小于 0.01 mm；十份源模型的基础颜色贴图通过解码像素比对。514 个未修改原网格保留几何、变换和 UV 指纹，分卷重组另有校验报告。详见 `validation/`。

交付是静态城市区块及区划资料，未包含游戏运行时导航、交通或碰撞接入。道路素材版权沿用原项目说明，建筑素材由用户提供。
