# 城市 v16：同色公寓分组、市政区收紧与黑边修复

基于 v15（`c07e0daefeef82c0d79274bef16ecf8b3b3d4f42`）。本次只替换 **06、07、08** 三个区块，其余 15 个区块沿用此前版本，世界坐标、米制比例及道路骨架保持原样。

- 北部剩余 36 号高楼移入 CBD，并按写字楼登记。CBD 现有 32 座，另保留原 172×195 m 的天明大厦用地，未来合计 33 座。
- 北部公寓区使用 50 号黄色、53 号粉色、54 号灰色三个楼型，每型 4 栋，共 12 栋。黄色组、粉色组、灰色组按街块分组，不混色交错；同型实例共享网格与贴图，保留模型原形和统一缩放。
- 市政区保留主楼，加入 51 号办公楼与 52 号宿舍，保留 4 栋配套占位楼，共 7 栋。范围由 34636.6 m² 收紧到 20154.2 m²，缩小约 41.8%，仍位于内陆。
- 移除原基础顶面和入口铺地的重叠，重建平台外沿回填和连续场地，清除旧市政入口留下的深色侧墙；保持正常楼体阴影。旧版检测到 41 处共面的基础，约 14,571.6 m² 重叠面，本版检查无超限的基础/铺地重叠。
- 全城建筑总数仍为 **664**，陆地仍为 **3.25 km²**。新增公寓和市政模型替换此前占位体块，多余市政占位体块已删除。

## 应用增量

先取得一套完整且校验通过的 v15 区块目录。保留该目录，再运行：

```bash
python3 reassemble.py --baseline-dir /path/to/v15/districts --out /path/to/v16/districts
```

脚本检查全部基准、每个分卷、压缩文件及解压后的 GLB。导入时保持根位置和旋转为 0、缩放为 1，先移除旧 06/07/08 再导入新版，不叠加加载。只取本次三个区块时，可以省略 `--baseline-dir`。

新旧 SHA256、区块建筑数量变化及具体备注见 `manifest.json`；当前 18 区块来源见仓库 `design/city/districts/current_sources_v16.json`。这次附带的五个原始素材和处理脚本用于后续复用与恢复，没有重复上传未修改区块。
