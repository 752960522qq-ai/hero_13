# 城市 v17：骑楼限量复用、老城收紧、公寓内迁

基于 v16（`8b3d8f6249f3da25f681c1aeb1f00144d0605d3b`）。只替换 **02、03、04、06、07** 五个区块，其余 13 个区块沿用原文件。

- 将 56、57 号模型加入骑楼池，池中共 10 型。按更严格的口径，**包含原有实例，每型全城最多 3 栋**：原有 8 型各新增复用 2 栋，新 2 型各使用 3 栋。本轮共替换 22 栋沿街占位楼，形成四段混合街面，保留原样板街。
- 老城清掉外围 123 栋占位楼。沿街楼由 243 栋（232 占位、11 正式）减至 **120 栋（87 占位、33 正式）**，80 栋后巷楼保留；老城合计 200 栋。沿街建筑外包范围由约 49.51 万 m² 收紧至 22.57 万 m²，未改道路骨架。
- 12 栋公寓全部迁入用户红圈所指的内陆地块，即天明大厦预留地北侧。黄色、粉色、灰色各 4 栋，按相邻两列分组，入口朝向院内步道；空出的沿海地面恢复。
- 骑楼按主体街面衔接，保留原比例和贴图，不镜像，不增加连续雨棚；已批准的 10 号转角模板保持原来的转向与深度适配。公寓重新做楼底、连续铺地及步道坡度，基础顶面与地面皮分开，避免宽黑边。
- 全城由 664 栋减为 **541 栋**。CBD 32 栋、市政区 7 栋、天明预留地、道路与海岸轮廓保持原状。

## 应用增量

先准备一套完整、校验通过的 v16 区块目录，运行：

```bash
python3 reassemble.py --baseline-dir /path/to/v16/districts --out /path/to/v17/districts
```

脚本验证全部基准文件、分卷、压缩流和解压结果；基准目录不会被覆盖。只取本次五个区块时可省略 `--baseline-dir`。加载时先移除旧的 02/03/04/06/07，再导入对应新版；根位置、旋转为 0，缩放为 1，勿叠加加载。

各区块 SHA256、建筑数量变化见 `manifest.json`；18 个区块当前来源见 `design/city/districts/current_sources_v17.json`。仅附带两份新原始 GLB、必要元数据、复现脚本及渲染，没有重复上传未改动区块或完整 Blender 工程。

## 验证与预览

原生场景检查覆盖 34 栋新增或迁移建筑的比例、贴地、道路及邻楼相交、天明预留地、同色分组与步道连接。五个 GLB 全部重新导入，世界坐标最大误差为 0 m；34 栋的基础颜色贴图经过解码像素比对。另保留 1005 个未修改原对象的几何、变换和 UV 指纹。报告见 `validation/`。

`previews/` 提供老城总览、骑楼街面、公寓内迁总览与院落近景。预览海面与其他区块仅作上下文，不写入本次增量。交付是静态城市资产，未包含游戏运行时导航、交通或碰撞接入。
