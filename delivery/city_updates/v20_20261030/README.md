# 城市 v20：弧线生活街与西岛曲街

基于 v19 `e9cd715cb39763a01c40a19255f6992a40ef2f79`，只替换 **04、08、09、10** 四个区块，另外 14 块按原 SHA256 沿用。

本轮采用 **13 种房屋模型，放入 49 栋**，移除 **11 栋西岛占位楼**。全城从 547 栋变为 **585 栋**，净陆地仍为 3.25 km²；老城沿街 120 栋、后巷 80 栋。

## 这次改了什么

- 新城弧线生活街：25 栋商住楼沿弯路改变朝向，采用短段连续街面，支路连接北侧主路。
- 新城商务组团：4 栋高低搭配的建筑，补齐之前备用的两种办公楼型，并建立独立入口步道。
- 西岛曲街：20 栋亚洲商住楼、社区店铺与坡顶住宅替换机械排列的占位楼；S 形街道与错位 T 字支路形成不同尺度街坊。
- 共增加 4 条道路，合计约 668.0 米，路口接入原有路网，包含人行道、路缘、中心线与斑马线。
- 公共设施：11 根电线杆、9 组架空线、6 盏路灯、38 棵树、14 组灌木花池、2 张长椅、1 个垃圾桶、3 根短柱。设施与线路单独计数，不占建筑额度。

重点参考 `city (1)(1).glb`（S05）的弧形主次道路、错位交叉口、街角种植与高低街面关系。按当前地形和已有路口重新建模，参考模型的未封闭背景楼片没有用作近景独立建筑。补传的两个模型与 S02/S08 原文件哈希相同，继续沿用原来源编号。
