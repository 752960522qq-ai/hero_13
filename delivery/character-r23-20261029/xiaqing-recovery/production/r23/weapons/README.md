# R23 枪械尺寸

用户指定的最终显示长度：汉阳造 950 mm、56 式 870 mm、QBZ95 750 mm。

保留武器原网格、纹理、形状、握持原点、支持手和枪口等本地坐标；只在 weapons.json 中修改统一挂载比例 displayScale。原本的 0.92 展示缩小系数已分别替换。

- 56 式：0.9666666922745888
- 汉阳造：0.7600000181198124
- QBZ95：1.0053619412194328

size-weapons.mjs 逐一读取所有实际顶点及节点变换，测整支武器枪管方向（+Z）的长度，不仅依赖旧 metadata。包括 56 式现有独立弹匣。
check-mounted.mjs 在四套角色的实际 Aim 动作、右手掌握持插槽和全部父级变换下，对枪管轴投影测量。12 个组合的最大误差约 0.000512 mm，小于 0.001 mm。详见 size-report.json 与 mounted-report.json。

运行脚本要求 Node 的 three 包使用当前网站 dist/vendor 的 Three.js 文件，且文件内站点根路径需指向本地已恢复的源码目录。脚本没有图片依赖，会跳过纹理解码，仅检查几何与变换。
