# 人物与网站备份：R23

包含夏晴 R23 网站（校服、武器与动作）、R21–R23 制作工程，以及英雄人物测试网站（双星、超人、原始模型与动作、Blender 工程和脚本）。分卷后的文件名以 .part001、.part002 结尾。

下载整个目录后，在本目录执行：

```sh
python3 restore.py
```

脚本按 manifest.json 重组分卷，并校验每个文件的 SHA-256 和长度。重组后，在相应 site 目录启动静态 HTTP 服务即可打开网站；各 production 目录包含可编辑 Blender 工程和制作记录。仓库中较早的夏晴备份仍单独保留。
