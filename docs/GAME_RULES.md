# HERO 13 游戏框架 · 数据与规则

当前网页游戏入口为 `xiaqing-motion-lab/dist/game.html`。在仓库根目录运行
`python3 -m http.server 8000 --directory xiaqing-motion-lab/dist`，浏览器访问
`http://localhost:8000/game.html`。原人物动作预览位于 `index.html`。

数据定义位于 `xiaqing-motion-lab/dist/game/data.mjs`，引擎与界面分开。
详细接口见 `xiaqing-motion-lab/dist/game/API.md`。本版本使用浏览器本地存档，
三名主角分别保存成长、生命体力、技能与物品，不引入服务端账户或在线同步。

## 属性与经验

每项属性独立累计 EXP。普通角色等级上限为 5，罗甄为 6；运气固定，
不参加经验升级。所有百分比均以 **0 级基础值**计算，等级加成线性相加，
不逐级复利。例如力量 4 级近战伤害为基础伤害的 `1 + 4×12% = 1.48` 倍。

|属性|效果（L 为当前等级）|经验来源|
|---|---|---|
|生命|生命上限 `100 + 20L`|每实际恢复 1HP，+3EXP；溢出治疗不计经验|
|体力|体力上限 `100 + 20L`；移动速度 `×(1 + 0.04L)`|跑步/游泳每 10m +5；跳跃/攀爬每 1m +2|
|射击|稳定性 `×(1 + 0.06L)`；换弹速度 `×(1 + 0.05L)`|每实际发射一发子弹 +5|
|驾驶|操纵性 `×(1 + 0.03L)`；载具极速 `×(1 + 0.02L)`|载具保持运动，每驾驶 100m +10|
|力量|近战伤害 `×(1 + 0.12L)`；近战速度 `×(1 + 0.03L)`|未命中 +5；命中 +20|
|魅力|社交加成 `×(1 + 0.05L)`|社交成功 +50；失败 +10|
|智力|制造速度 `×(1 + 0.06L)`；制造损耗 `×(1 - 0.06L)`|制造成功 +50；失败 +10|
|运气|正向概率 `p×(1 + 0.06L)`；负向概率 `p×(1 - 0.05L)`|固定，不可升级|

随机概率最终限制在 0—100%。距离不足一次计量的部分保留，随后累计。
升级门槛是“当前等级到下一级”所需经验：

|升级|EXP|
|---|---:|
|0→1|1000|
|1→2|1500|
|2→3|2500|
|3→4|5000|
|4→5|10000|
|罗甄 5→6|18000|

载入旧存档时，原先在 5 级积存的 EXP 会按 18000 门槛结算，可直接升至 6 级。

速度加成指单位时间效率提高，例如制造耗时应为基础耗时除以制造速度倍率，
不能直接把秒数减少同一百分比。制造书使用目录固定耗时，不适用智力加速或损耗优惠。

## 专属技能

技能初始为 0 级。当前原型范围暂按普通角色 0—5、罗甄 0—6 实现；
“共五级”是否包含 0 级、罗甄专属技能是否同样为 6 级仍需后续确认。
技能升级获得方式尚未给定，界面的“原型配置”可手动预览等级，
不提供虚构的技能经验消费方式。

### SKL_001 完美身法

- 罗甄独占，能量条开关，再按取消；完全充能 120 秒。
- 开启时世界时间为 0.5 倍；最大持续 `6 + 2L` 秒。
- 基础闪避概率 `14% + 10%L`，再乘罗甄运气正向倍率，封顶 100%。
- 闪避提示窗口是攻击前 `0.4 + 0.1L` 个正常世界秒；慢时状态下对应
  `0.8 + 0.2L` 个现实秒。
- 隐藏反击窗口是攻击前 `0.1 + 0.05L` 个正常世界秒。成功闪避并落在
  该窗口内时出现反击机会，仍需按反击按钮。
- 反击基础伤害 30，接受力量加成；轻/中/重型眩晕分别为 5/3/1 秒。

### SKL_002 杀神本能

- 徐哲独占，持续 `8 + L` 秒，冷却 100 秒。
- 伤害减免 `30% + 10%L`；近战加成 `20% + 5%L`；射击加成 `10% + 2%L`。
- 开启期间射击不消耗子弹。力量近战倍率与技能近战倍率分别作用。
- 冷却按技能使用时开始计时；这一时点作为原型约定，后续可调整。

### SKL_003 巧手灵心

- 夏晴独占，点击技能就地打开制造书。物品完成后进入物品栏。
- 思考上限 `100×(1 + 0.15L)`；基础充能速度 `100/90` 点每秒，
  当前速度再乘 `1 + 0.10L`。
- 思考需要主动开启，可暂停；期间仅允许步行，剧情开始时自动停止。
- 制造书的点数与时间完全取目录，排除智力加成；每次完成制造仍获得 50 智力 EXP。

## 当前待定项与范围

- 罗甄成长速度额外倍率、专属技能升级获得方式：保留空配置，不编造数值。
- 技能总等级范围和徐哲冷却起点：采用上文明确标注的原型约定。
- 体力消耗/恢复、普通枪械与近战基础数值、敌人 AI、关卡、剧情内容、载具模型：
  本轮没有详细设定。演练场使用显式事件参数来验证已有系统，不伪装成完整关卡。
- 护甲可维修，但修理配方/成本未给定；保留维修接口，维修工具只用于载具。
- 普通制造、社交等外部玩法通过事件接口传入实际成功/失败结果；数据层不虚构成功率。

所有缺失资源及规则均可追加，稳定 ID 与纯逻辑引擎接口可供后续网页或引擎接入。
