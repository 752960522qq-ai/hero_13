## 姿态修改

- Idle：按手腿间距动态收拢双上臂，向内修正约0.1–6.95度，贴近大腿时减小修正，宽松时多收一点；平滑处理整段曲线及首尾，保留呼吸和侧倾。仅改8条上臂四元数曲线。
- Run：把额外颈部前探收敛到约28度的颈骨轴前倾，保留身体奔跑前倾；头部补偿一半修正角，避免过度昂头。仅改 neck_0 和 head 的8条四元数曲线。
- Aim：从用户上传 `Rifle Aiming Idle.fbx` 迁移。原片3.1秒，含完整手指链；54根目标主骨/指骨映射，包含30个对应指节。根据既有原生骨架休止朝向和掌面适配，固定根高度与腿部姿态修正使高跟鞋站稳。原文件没有步枪模型，本轮加入动作与握持手势，不虚构枪械。

`merge_report.json` 确认最终网格坐标、拓扑、蒙皮权重及骨架休止矩阵与 R6 一致，没有重新改变人物比例或小腿绑定。

## 必要复看

五处待机关键姿态中，手腿三角面无相交，最小采样顶点间距约18毫米。三处跑步复看中颈骨轴前倾约28–28.3度。瞄准使用代表姿态的正面、侧面和手部图复看；四动作GLB的骨骼数量、有限数据和四权重归一导出检查通过。没有重复执行旧版全套验证或浏览器检查。

`comparison.html` 保存修改前后图片与瞄准图。`aiming/` 保存原始FBX、重定向程序、映射、动作关键帧和报告。`editable_data/` 为当前骨架、完整蒙皮及四段动作关键帧的独立数据；材质和内嵌贴图以最终Blender为准。

网站已更新角色文件、缓存版本与“瞄准”按钮。移动时临时行走、停下返回瞄准，使用同一固定站立偏移，不逐帧强制贴地。

## 重建

在本目录依次用 Blender 执行：

```sh
blender -b -t 4 --python pose_adjustments/fix_idle_run.py
blender -b -t 4 --python aiming/retarget_aim.py
blender -b -t 4 --python merge_r7.py
blender -b -t 4 --python export_r7.py
blender -b -t 4 --python extract_editable_data.py
```

`Aim` 在 Blender 中保持0–74.4帧（24fps、3.1秒），运行导出按整帧采样，因此显示长度可有不到一帧的量化差异。原有头颈纹理细褶仍可后续精修，关节自然弯曲不等同于网格休止比例变化。
