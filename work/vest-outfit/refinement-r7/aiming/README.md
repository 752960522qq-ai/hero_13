# Rifle Aiming Idle → 夏晴 Aim

上传源文件 `Rifle Aiming Idle.fbx` 已原样保存在本目录。源为65骨 Mixamo 人体及其示意网格，单段动作为30fps、1–94帧、3.1秒；文件没有步枪模型。

`retarget_aim.py` 使用现有 R6 的437骨原生骨架，按解剖子关节点方向、掌面坐标与指骨坐标转移旋转；不复制源人体尺寸、骨骼缩放、水平根运动或源网格。映射54根目标主骨，包括30个指节；原生无对应的4根掌骨保持既有绑定并跟随手腕。完整映射见 `retarget_report.json`。

目标动作名 `Aim`，24fps时间轴为0–74.4帧，75个采样点，保持3.1秒。源末帧微小接缝在最后10个目标帧平滑回首帧，保留瞄准呼吸与握持姿态。原三套动作保留。

沿用R6刚性高跟鞋的小幅踝骨运动。为适配原身体比例，在一个中间姿态求解两腿站姿，再将4个固定腿骨旋转偏移应用于全段；根部采用同一个约-24.986毫米的高度，不逐帧强制贴地。中间姿态两鞋最低点约为-0.00954/-0.00965米。股、胫骨姿态只做这一固定适配，网格、蒙皮、骨骼休止矩阵和身材比例均未改。

`aiming_candidate.blend` 仅供主线程追加 `Aim` Action；临时源人形与其骨架已删除。`Aim_front.png`、`Aim_side.png`、`Aim_hands.png` 为一次代表姿态复看，不含虚构枪械。后续有枪械资源时，可按实际握把与承托点装配；本轮只引入动作。

`aim_rotation_keys.npz` 保存75采样的映射骨旋转；固定COG高度、源映射、腿部常量修正及时间规则见JSON与脚本。主线程最终R7工程与其四动作GLB是完整交付，本子目录没有部署或推送。
