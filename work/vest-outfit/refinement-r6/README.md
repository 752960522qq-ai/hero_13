## 原因与修复

旧适配已在网格休止坐标中写入非等比拉配。小腿原本应统一缩放1.7倍，旧小腿的仿射主缩放约2.05/1.72/1.52，上段横宽较源人体窄约10–14%。单改蒙皮无法恢复已经变形的休止网格。

本轮把下身按原始源坐标恢复，使用与现有原形肩颈一致的统一变换：scale=1.7，translation=[-0.0002340783,-0.1259081221,-0.0096482595]。源高度z≤0.60的下身恢复原形，在0.60–0.65向既有腰部平滑衔接；排除手部。原鞋作为完整刚体整体对齐，不改鞋跟、厚底或鞋带内部形状。骨架据此匹配原人体髋、膝、踝，包含38根腿部主骨及辅助骨的位置校正。

小腿肌腹采用同侧 tibia 单骨保形绑定，大腿肌腹采用 femur 单骨驱动；膝、踝、髋附近保留短带过渡。消除原脚踝混合覆盖小腿下半段的问题。原有源法线按原三角面与顶点编号恢复。

为适配厚底高跟鞋，三套动作中24条踝骨四元数曲线采用连续的小幅旋转，平滑限制为3度以内；保留原时间、动作方向和循环连续性。髋、膝、躯干、手臂、手指动作曲线保持 R5。用户此前的待机手腿间距修复继续保留。

## 必要复核

- 休止下身与原始等比坐标的最大残差约5.61e-8米。
- 休止与 Idle/Walk/Run 各一个选定时刻中，小腿肌腹边长比约0.99997–1.00003，鞋体保持刚性；复看中小腿横向挤压带已消除。
- 在三处待机关键姿态复查手腿表面，没有三角面相交，最近采样手部顶点到大腿约18.9毫米。
- GLB 导出保留35个角色网格、437根骨骼、三套动作，有限数据及四权重归一检查通过；右侧原始参考不进入 GLB。

这些针对本次问题的检查不代表所有新动作都无需适配。膝踝关节允许自然弯曲过渡，既有头颈细褶不在本轮修改范围内。恢复原始下身后，模型鞋底相对原点的位置随之改变；后续部署应重新按新模型调整网站整体站立高度，不能照搬 R5 的整体抬高值。
