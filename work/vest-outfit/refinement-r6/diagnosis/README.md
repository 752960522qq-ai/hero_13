# R6 小腿只读诊断

输入为 R5 工程与原始背心人体处理后的源顶点，未修改模型或动画。

## 主要结论

1. **静止网格已被过去的 RBF 适配拉扁、拉长**。左右小腿与原始源形的最佳等比拟合仍有约11.1–11.2 mm平均残差、17.5–17.7 mm P95残差；最佳仿射缩放主值约 `[2.05, 1.72, 1.52]`，原素材应只接受统一1.7倍变换。上段小腿横宽较源形约窄10–14%。此问题在 REST 状态已经存在，单改蒙皮不能还原 REST 原形。
2. **骨骼没有动画缩放或继承剪切问题**。Idle/Walk/Run 中未找到腿、骨盆、脊柱 scale 曲线。采样的 tibia/ankle 皮肤变换矩阵奇异值均为1（误差约3e-7），每个骨骼变换本身保持形状。
3. **剩余动作变形来自混合范围过宽**。R5仍让脚踝影响从源Z≈.208/.211延伸至.300，覆盖约15厘米的小腿下半段。骨骼各自刚性，但线性蒙皮混合脚踝和胫骨旋转会弯曲、挤压肌腹。
4. **膝关节仍不匹配源形**。按当前原鞋的等比变换，源膝中心约Z=.4934m；当前tibia头约Z=.5359m，高约42.5mm。原鞋变换Tz=-.110094，与颈部原源形变换Tz=-.009648相差约100.45mm，说明上下身之前被独立拉配到不同高度。

## 建议

先并排放置等比原人体确认静止轮廓。若要求原素材身材不失调，应恢复原始顶点的统一等比位置，并将骨骼匹配身体；不要继续用局部缩放、RBF或额外挤压来迎合旧骨架。当前鞋仍是原形，可作为整体平移跟随统一身体坐标，不改变鞋体内部形状。

肌腹（源Z≈.235–.345）采用单一同侧tibia刚性驱动，脚踝混合局限在靠近鞋腿接边的源Z≈.208–.235，膝部混合局限在源Z≈.345–.375。只有关节邻近带允许柔性过渡，肌腹和鞋体应分别保形。

`leg_diagnosis.json` 包含逐侧静止截面、源形残差、骨骼位置和选定姿态的皮肤矩阵、局部边长比。
